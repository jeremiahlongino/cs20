Movie API

API Deets

I chose the Open Movie Database (OMDB) API, mainly because it was one of the examples of a free API that I looked up but also because it's pretty cool. It gives movie data in the JSON format and allows searching for movies too.

Source: https://www.omdbapi.com/

Parameters: The request uses "s=" to search by movie title and "apikey=" for authentication.

Use Case: I would definitely use this API to just search for movies to watch, but it would also be useful to have this plus like the Wikipedia API for more detailed information. For movies that I find interesting, but not enough to watch (or pay for), this API would be a great resource to find info all in one place.
